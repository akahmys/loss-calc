# Loss Calc Security, License & Compliance Protocol

This document defines dependency security, open source license auditing, and data protection standards for **Loss Calc**.

---

## 1. License Policy

Third-party npm dependencies are strictly restricted to permissive open-source licenses (MIT, Apache-2.0, BSD, ISC, etc.).

---

## 2. Client-Side Data Protection

This application operates locally in the user's browser, ensuring calculation parameters and piping design data are never transmitted to external servers without explicit user request.
